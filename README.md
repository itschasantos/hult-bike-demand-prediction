# Bike Rental Demand Prediction

Individual Hult coursework by Charlynne Santos. Explores weather and time features and compares regression models for bike rental demand.

## Run locally

Use Python 3 in a virtual environment, install the packages in `requirements.txt`, and open `analysis.ipynb` in JupyterLab. Run cells in order.
